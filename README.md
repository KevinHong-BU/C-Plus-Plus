## 1장 C++ 개요와 개발 환경

C++의 특징을 이해하고, 첫 프로그램을 작성·빌드·실행하는 것이 목표입니다.

### 1.1 C++의 역사와 특징

- C에서 파생된 배경, 표준화 흐름(C++98 → 11 → 14 → 17 → 20 → 23)
- 절차지향·객체지향·일반화 프로그래밍을 모두 지원하는 멀티 패러다임 언어
- 활용 분야: 게임 엔진, 시스템 소프트웨어, 임베디드, 금융·고성능 컴퓨팅

### 1.2 컴파일 과정

- 전처리 → 컴파일 → 어셈블 → 링크 단계와 각 단계의 산출물(.cpp, .o/.obj, .exe)
- 헤더 파일과 소스 파일의 역할, #include의 의미
- 컴파일 오류와 링크 오류의 차이

### 1.3 개발 환경 구축

- 컴파일러: GCC(g++), Clang, MSVC
- IDE/에디터: Visual Studio, VS Code, CLion, 온라인 컴파일러(Compiler Explorer 등)
- 표준 버전 지정 옵션(-std=c++20)

### 1.4 첫 번째 프로그램

- Hello World 분석: main 함수, std::cout, 네임스페이스 std
- 주석, 들여쓰기, 코딩 스타일 기초
- using namespace std 사용 시 주의점

## 2장 기본 문법: 자료형, 변수, 연산자

데이터를 저장하고 계산하는 기본 도구를 익히는 것이 목표입니다.

### 2.1 기본 자료형

- 정수형(int, short, long, long long), 실수형(float, double), 문자형(char), 논리형(bool)
- sizeof 연산자와 자료형 크기, signed/unsigned
- 고정 크기 정수형(int32\_t 등)

### 2.2 변수와 상수

- 변수 선언과 초기화 방식: = 초기화, () 초기화, {} 균일 초기화
- const와 constexpr의 차이, 리터럴 상수
- auto를 이용한 타입 추론 기초

### 2.3 연산자

- 산술·대입·비교·논리·비트·증감 연산자
- 연산자 우선순위와 결합 방향
- 정수 나눗셈, 오버플로우 등 흔한 실수

### 2.4 형 변환

- 암시적 형 변환과 데이터 손실
- C++ 캐스트 연산자: static\_cast, const\_cast, reinterpret\_cast, dynamic\_cast(개관)

### 2.5 표준 입출력

- std::cin, std::cout, std::endl과 '\\n'
- 입력 오류 처리 기초, getline
- 출력 형식 지정(iomanip, std::format 소개)
